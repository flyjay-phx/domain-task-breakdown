# 자기 도메인 업무 분해 예시 — 수업 후 학습내용 정리

OT 노드 05 "Computational Thinking" 과제 제출물입니다.

## [도메인 맥락]
나는 AI 에이전트 과정(3기)을 수강 중인 입문 학습자이고, 매 노드가 끝난 뒤 **그날 배운 내용을 팀 노션 템플릿(학습내용정리 / 의문 및 토론 / 오늘의 회고)에 정리하는 작업**을 정리·자동화하고 싶습니다. 노드마다 7시간짜리 레슨을 읽고 팀원과 같은 양식에 맞춰 써야 해서, 매번 같은 구조를 처음부터 다시 만들고 있습니다.

## [네 동작 분석]
1. **분해**: 노드 하나를 ① 핵심 한 문장 ② 개념 단위(예: 에이전트, 하네스, MCP, 스킬) ③ 실습에서 직접 한 일 ④ 아직 못한 일 ⑤ 생긴 의문 ⑥ 회고 3문항으로 나눈다.
2. **패턴**: 모든 노드가 "핵심 한 문장 → 개념 설명 → 실습 → 과제 → 회고"의 같은 순서로 구성되고, 노션 페이지도 매번 같은 세 칸(학습내용 / 질문사항 / 회고)이다.
3. **추상화**: 7시간 분량을 "한 줄 요약 + 개념 5~6개(각 한 문장) + 한 일/못한 일 목록"으로 줄이고, 출처 목록·역사 이야기 같은 세부는 버린다.
4. **알고리즘**: 레슨 읽기 → 섹션별 핵심 문장 추출 → 실습 결과와 개념 연결 → 한 일과 못한 일 분리 → 노션 규격 마크다운으로 출력 → 팀원 정리와 비교해 빠진 개념 확인.

## [출력 요구]
노션에 그대로 붙여넣을 수 있는 마크다운(제목, 번호 소제목, 불릿)으로, 한국어 존댓말, 한 페이지 분량.

## [검증 기준]
같은 팀의 이끄미(팀원 한 명)가 "이 정리만 읽고도 오늘 노드의 핵심 개념을 팀원에게 설명할 수 있다"고 평가할 것. 못한 일이 숨김없이 적혀 있는지도 함께 본다.
